Signed-in home: vertical centering & viewport overflow

The signed-in home page sits above true center and the page overflows the viewport by roughly the nav's height, producing a stray scrollbar. Root cause: .flow-page keeps min-height: 100vh even when it is a flex child beneath the nav, so the shell totals 100vh + navHeight.

Use the controls to compare the broken state against the two proposed fixes. Toggle the device width and auth state — the bug only reproduces when signed in (signed-out has no nav, so .flow-page ≈ viewport).

Current

Broken

.flow-page { min-height: 100vh } + nav ⇒ shell is taller than the viewport. Content centers inside the 100vh box, which is pushed down by the nav — reads as off-center, and the page scrolls.

Preferred

Option A · flex fill

.flow-page { flex: 1; min-height: 0 }. The column flex of .app-shell hands the flow-page exactly the leftover height. No magic number, no overflow, content centered in the visible area.

Alternative

Option B · calc()

.flow-page { min-height: calc(100vh - navHeight) }. Works, but depends on a hard-coded nav height — drifts if the nav wraps or fonts shift its height.

The single-line change

/* src/frontend/styles/flows.css */
.flow-page {
  min-height: 100vh;
  flex: 1;
  min-height: 0;
  display: flex;
  align-items: center;
  justify-content: center;
  padding: 40px 20px;
}

Option A Requires .app-shell to be the flex parent — it already is (display:flex; flex-direction:column in App.vue). The router-view's single root .flow-page becomes the growing child. Signed-out is unaffected (still fills 100% with no nav).

Why Option A over B / mobile note

  • No magic number. Option B's calc(100vh - 49px) breaks if the nav height changes (font load, longer display name wrapping, future nav items).
  • Mobile override needs review. The current @media (max-width:767px) rule sets .flow-page to align-items: flex-start; padding-top: 48px. With flex:1 the page no longer overflows; keep top-aligned for tall forms, but the home screen is short enough to center — recommend align-items:center here (decision flagged below).
  • Regression surface. Every flow screen (login, signup, create, join, guest, lobby, game-over) uses .flow-page. Fix is shared — verify all of them still center and tall forms still scroll internally.
