CSS Fix — src/frontend/component/HomeView.vue (<style scoped>) 

 .home {
   text-align: center;
   max-width: 500px;
+  width: 100%;
 }

Why this works: The .flow-page flex container centers its children via justify-content: center. Without width: 100%, the .home div shrinks to its intrinsic content width (about 300px from .home__actions). The margin: 0 auto on .home__actions becomes a no-op because the parent is already content-sized. Adding width: 100% makes .home fill the available space (capped at max-width: 500px), giving margin: 0 auto room to center the buttons within. On mobile, where align-items: flex-start removes cross-axis centering, width: 100% ensures the container spans the full viewport width minus padding, keeping buttons centered via the auto margin.

Regression Check — Other Flow Pages

The fix only touches .home (scoped style in HomeView.vue). Other flow pages (Login, Signup, CreateGame, JoinGame) use .form-card which already has width: 100% and max-width: var(--page-max-width). No changes needed — no regressions possible. 

/* flows.css — .form-card already correct */
.form-card {
  ...
  width: 100%;            /* already present */
  max-width: var(--page-max-width);  /* 420px */
}
