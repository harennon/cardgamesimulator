Public "Join by Room Code" — Signed-out Home

Give signed-out users a first-class way to type a 4-letter room code and reach the existing guest-entry name prompt — no account, no clickable link. This is a secondary control added to the existing signed-out HomeView, above the Log In / Sign Up prompt. Three input treatments are shown; all share the same layout, state, and flow. Signed-in Home is unchanged.
