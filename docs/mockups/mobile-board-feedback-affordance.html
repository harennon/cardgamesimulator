Mobile board — feedback affordance

On the mobile game board (/game/:gameId, ≤767px) the help cluster collapses to just the ? FAB, hiding the only bug / feedback trigger in the app. Three ways to give mobile players back a reachable path to the feedback modal without shrinking the hand or overlapping the Play/Pass action row. All reuse the shipped visual language (dark felt, gold accent, DM Sans + Libre Baskerville) and open the same FeedbackWidget modal with full game-context metadata.

Option A · Recommended

Fold into a top-right board menu

The mobile log toggle (☰) becomes a small overflow menu: Game Log + Report a bug. The bottom cluster stays a single ? FAB — hand unchanged. Uses existing top-right real estate that never overlaps the hand or action row.
