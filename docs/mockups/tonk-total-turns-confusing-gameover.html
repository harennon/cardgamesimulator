Tonk game-over — fixing the confusing "Total Turns" value

On the Tonk results screen, Total Turns currently binds the engine's internal turnNumber, which ticks on every discard and every draw (two per real turn) and again on each round reset — never resetting across the multi-round match. A four-player game easily reaches the reported 192. It is an internal sequence number, not a figure a player can reason about.

Below are three distinct resolutions, each shown inside a faithful copy of the real GameOverView panel. Big2 is untouched in all three (see the comparison at the bottom).

Today (bug): Tonk shows Total Turns: 192 — inflated, double-counted, cumulative across rounds. No player intuition maps to it.
The real, reasonable number: Tonk already counts rounds in-game as TRICK 1 … TRICK N (tally panel + phase banner). The final trickNumber is the rounds-played figure a player has literally watched count up. In this scenario that is 4.
Option A · Hide the row for Tonk
Simplest, lowest-risk. The metadata line renders only for game types with a meaningful turn count (Big2). Tonk shows nothing between the score table and the stat grid — no wrong number, no new vocabulary.
