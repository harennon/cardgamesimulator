Recommendation. Small card: Option B (drop the corner; centered rank + suit only) — cleanest at thumbnail scale, smallest code change, and adds .card--small-scoped rules without touching medium/large. Alignment: Option 1 (fixed-width name column) — minimal markup change, keeps each entry compact, and guarantees a consistent card start x regardless of display-name length. Options 2/3 are stronger if you want roomier rows or a more "table-like" fan.
