Bug fix · Issue #139 · Route /game/:id

CPU seats no longer show a false "disconnected" label

AI seats never open a WebSocket, so the backend correctly reports isConnected: false for them — but they are always server-driven and taking their turns normally. Today both boards render a red disconnected label under every bot. The fix guards that label so it only appears for genuinely offline humans. The CPU badge (steel blue) and gold turn-glow are untouched.

Gold glow / border = whose turn it is
CPU badge = seat identity (AI)
"disconnected" = human seat with no active socket
