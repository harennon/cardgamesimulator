Issue #24: Card Selection Animation Feels Slow on Mobile

Root cause: The original transition used 150ms ease for the card lift on selection. The ease timing function (CSS default cubic-bezier) starts slowly — on a small 14px mobile lift, the first ~50ms show almost no visible movement, making the tap feel unresponsive. On desktop the 20px lift over 150ms is perceptible enough; on mobile the shorter distance amplifies the perceived lag.

Reported on: Firefox Android, 395x804 viewport.
Original code: transition: transform 0.15s ease in GameCard.vue
Before 150ms ease (the problem)

This is what the user reported as slow. The cubic-bezier(0.25, 0.1, 0.25, 1.0) starts with very low velocity — the card barely moves in the first 50ms after tap.

transition: transform 150ms ease;
transform: translateY(-14px);
Option A 80ms ease-out

Shorter duration + ease-out curve. The card jumps immediately on tap (high initial velocity) then decelerates into position. Sub-100ms feels instant to the human brain while still providing a subtle animation rather than a hard snap.

transition: transform 80ms ease-out;
transform: translateY(-14px);
Option B 150ms ease-out

Same duration, different curve. The ease-out means the card responds immediately (full velocity at start) then settles. More visible animation than Option A but still removes the initial lag. Minimal code change.

transition: transform 150ms ease-out;
transform: translateY(-14px);
Option C No transition (instant)

Zero animation on mobile. Card snaps into selected position immediately. Maximum responsiveness. Desktop retains 150ms ease for mouse hover feel. Also honors prefers-reduced-motion.

--card-select-duration: 0ms; /* mobile */
--card-select-easing: linear; /* mobile */
/* desktop keeps 150ms ease */

Implementation (Already Applied)

The fix introduces two CSS custom properties in game-variables.css and consumes them in GameCard.vue.

  • Added --card-select-duration: 150ms and --card-select-easing: ease to :root (desktop defaults)
  • Overridden to 0ms / linear inside the existing @media (max-width: 767px) block
  • Added @media (prefers-reduced-motion: reduce) override: --card-select-duration: 0ms
  • Updated GameCard.vue transition shorthand to use the variables: transition: transform var(--card-select-duration) var(--card-select-easing)
  • No component logic changes, no new files, no prop changes
