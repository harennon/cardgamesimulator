STATE MANAGEMENT
════════════════

New local state (ref):
  codeCopied: boolean — drives toast visibility + icon swap (checkmark vs clipboard)
  Timer: setTimeout resets codeCopied=false after 2000ms

Computed:
  shortCode: string — derived from props.gameId
    Logic: gameId.slice(0, 8).toUpperCase(), split into "XXXX XXXX" (space at index 4)
    Rationale: 8 hex chars = 4 billion combinations, sufficient for active game disambiguation

Methods:
  copyGameCode(): void — navigator.clipboard.writeText(props.gameId), sets codeCopied=true
  copyInviteLink(): void — existing behavior, copies full URL

No new composables. No new props. Purely additive template/style change.

INTERACTION MODEL
═════════════════

1. User sees "Room Code" label + large monospace code "A7F2 B9D1"
2. User taps code → clipboard.writeText(full gameId) → gold flash animation
3. Icon swaps from clipboard to checkmark for 2s
4. Toast "Copied to clipboard" fades in below code, fades out after 2s
5. User can also tap "Copy Full Invite Link" for the URL (existing behavior)
6. For verbal sharing: user reads the 8-char code aloud to friend
7. Friend enters code in "Join Game" screen (existing flow, accepts gameId prefix match)

DATA FLOW
═════════

gameId (prop from GameView parent)
  → shortCode (computed, display-only)
  → copyGameCode() writes full gameId to clipboard
  → Server join endpoint accepts full UUID OR prefix match (future enhancement)

Design Decisions

1. CODE FORMAT: First 8 chars of UUID, uppercased, grouped as "XXXX XXXX"
   - 8 hex chars provides 4B+ unique codes — no collision risk for concurrent games
   - Grouping into 4+4 aids verbal communication ("alpha seven foxtrot two, bravo nine delta one")
   - Uppercase for readability on small screens and to distinguish 0/O, 1/l

2. TAP-TO-COPY ON CODE ITSELF (not a separate button)
   - The code element IS the tap target — reduces cognitive load
   - Copy icon hints at interactivity; gold flash confirms action
   - Saves vertical space on mobile (no extra "Copy Code" button)

3. "COPY FULL INVITE LINK" AS SECONDARY
   - Demoted below the code — still available for pasting in chat apps
   - The primary use case (verbal sharing) needs the code, not the link

4. NO BACKEND CHANGES REQUIRED
   - gameId (UUID) already exists and is passed to the lobby
   - Display is purely a frontend computed property (slice + format)
   - Join flow already accepts gameId — prefix-matching is a future nice-to-have

5. OPTION A RECOMMENDED because:
   - Stronger visual hierarchy — code demands attention
   - Gold border creates clear tap affordance without explicit instruction
   - Casino chip aesthetic matches game theme
   - The problem is specifically that users CANNOT FIND the code; making it subtle defeats the purpose
