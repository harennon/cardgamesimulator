Component Architecture

GameLobbyView.vue (modified)
  Props: { gameId: string, players, maxPlayers, isHost, actionPending }
  New computed: shortCode — gameId.slice(0,8).toUpperCase(), split "XXXX XXXX"
  New method: copyGameCode() — copies shortCode to clipboard, shows toast

  Template changes:
    Replace .lobby__invite section with:
      .invite-section
        span.invite-label       — "Room Code — tap to copy"
        .invite-code            — tap target (the gold-bordered chip)
          span.invite-code__text  — formatted short code
          span.invite-code__icon  — copy/check SVG icon
        span.invite-code__toast — "Copied to clipboard" (shown 2s)
        button.invite-link-btn  — "Copy Full Invite Link" (existing behavior)

  Layout strategy:
    Flexbox column, full-width within lobby panel.
    invite-section gets border-top separator from players list.
    On mobile (<=767px), panel padding shrinks (24px 18px vs 40px 48px).

  State management:
    codeCopied: ref — drives toast visibility + icon swap
    linkCopied: ref — existing "Copy Invite Link" toast
    Both use setTimeout(2000ms) reset.

  Interaction model:
    1. User taps .invite-code container
    2. navigator.clipboard.writeText(shortCode) called
    3. codeCopied = true, icon swaps to checkmark
    4. Gold flash animation plays (CSS @keyframes, 500ms)
    5. Toast fades in below
    6. After 2s: codeCopied = false, icon/toast revert

  Join flow integration:
    The short code (first 8 chars of gameId) is sufficient because
    the Join Game page already accepts partial IDs via prefix match.
    No backend changes needed if join accepts gameId prefix lookup.
    Alternative: display full gameId but format first 8 prominently.

  No new composables needed — purely local component state.
  No new shared types — uses existing gameId: string prop.
