In-Game Room Code Display

Three distinct placements for surfacing the 4-character room code during active gameplay (IN_PROGRESS). Each shows the desktop board (left) and a phone (right). The code is always visible, never overlaps the cards or action buttons, and copies to clipboard on tap. Click any code element to see the copy feedback.

Option A

Opponents-bar corner tab

A compact pill anchored to the far-right of the opponents bar — the one strip of the board that never holds cards. Label "ROOM" sits beside the monospace code with a small copy glyph that brightens on hover. Reuses dead space in the top bar; zero new vertical chrome. On mobile it collapses into a stacked label/code that hugs the top-right corner.

Option B

Felt-engraved chip (lower-left)

An inset "engraved into the felt" pill floating at the lower-left of the play area, above the hand. A small gold dot, the literal code, and the word "Room". Treated as part of the table surface (inset shadow, no hard border) so it recedes until looked for. Sits clear of cards and the centered last-play. On mobile it shrinks and drops the helper text.

Option C

Opponents-bar left slot (label + code)

A stacked "ROOM CODE" label over the code anchored to the far-left of the opponents bar, mirroring the lobby's chip styling at miniature scale. More explicit and discoverable than A (full "ROOM CODE" label, larger code, wider letter-spacing) while still living in the dead space of the top bar. Balances the active-turn timer that appears on the right.

Recommendation: Option A (opponents-bar corner tab). It reuses the one zone guaranteed to be card-free, adds zero vertical chrome to a viewport-locked board, and reads as a peer to the per-opponent timer already living in that bar. Option C is the most discoverable if we want the code to be obvious to new users; Option B has the most character but floats over the play surface and risks crowding on 2-player layouts.

All three: tap copies to clipboard (reuses lobby's navigator.clipboard.writeText + "Copied!" toast pattern), with a title/aria-label of "Room code H7K3. Tap to copy." and a clipboard fallback ("Long-press to copy.") matching GameLobbyView.vue.
