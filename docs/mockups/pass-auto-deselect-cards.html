Frontend Mockup · Big2 Game Board

Cards lower back into the hand when you Pass

Today, selecting cards and then pressing Pass leaves those cards stuck raised out of the hand — and because cards can only be toggled on your own turn, you can't click them back down until your next turn. The fix mirrors the existing play-flow behavior: clear the selection on pass, so raised cards animate smoothly back to rest.

Implementation note (mirrors the existing play flow): The raised state is driven entirely by the selection set (selectedIndices → card--selected). The fix adds clearSelection() to onPass() in GameView.vue, exactly as onPlay() already does on a successful play. No new transition is introduced — cards fall back using the existing --card-select-duration / --card-select-easing tokens on the card's transform. No change to pass/play server behavior.
