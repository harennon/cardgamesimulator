Mobile discard pile fit — 5-card play (iteration 2)

Re-design after feedback that the first pass (scale / shrink only) did not keep the discard on screen, and that the discard pile should not shift around relative to the played cards. Every option below applies the same structural change first, then varies how the played row is fit.

Core change shared by all options: the discard (trick) pile is decoupled from the played-cards composition. On mobile it is anchored to a fixed spot — bottom-left of the felt — so it never moves when the play gets wider, and it stops pushing the centered play past the right edge. The options differ only in how the played row itself is made to fit.

How to read this

  • Each phone is a real CSS viewport width (360px / 320px) with overflow:clip, exactly like the production mobile board.
  • The discard/trick pile is the small angled mini-stack with the gold count badge. In every option it now sits in the bottom-left corner of the felt and never moves when the play changes.
  • Switch the Current play tabs above to confirm single, pair, and 5-card combinations all stay fully on screen and centered.
  • Option A needs a tiny ResizeObserver/JS measure to set the scale; B and C are pure CSS.
