What every direction guarantees (the acceptance criteria)

  • Continue button uses 100dvh-based sizing and is pinned to the visual viewport bottom (env(safe-area-inset-bottom) aware), so it stays fully visible and tappable when the mobile URL bar reveals on scroll. Toggle Mobile + URL bar Shown to confirm.
  • The board behind the reveal is blurred + dimmed, so leftover board detail (turn timer, room code, action panel) reads as background, not interactive UI.
  • The stale "'s turn" label is suppressed at game over (no current turn). Toggle "Stale 's turn (bug)" to see the orphaned text this fix removes — the timer/turn UI is hidden once the game is over.
  • Final winning cards stay crisp and prominent above the blur, with winner announcement and the click-to-continue affordance (no auto-advance timer, per LLD 73).
