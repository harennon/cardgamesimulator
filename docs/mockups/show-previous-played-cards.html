Design Specifications

  • Opacity progression: Current = 1.0, age-1 = 0.55, age-2 = 0.32, age-3 = 0.18
  • Scale progression: Current = 1.0, age-1 = 0.82, age-2 = 0.68, age-3 = 0.56
  • Card sizes: Current uses "medium" (64x90px), age-1 uses "small" (40x56px), age-2+ uses "tiny" (28x40px)
  • Transition timing: 350ms cubic-bezier(0.22, 1, 0.36, 1) for slide-in; 400ms ease for fade-out to history
  • History depth: Show last 2-3 plays from the current trick only (resets on new trick)
  • Passes: Shown as italicized text labels (no cards) to save horizontal space
  • Separator: Subtle vertical gold gradient line divides history from current play
  • Mobile adaptation: History moves below the current play in a compact row; only 1-2 previous plays shown
  • Data source: Derived from existing playHistory array in Big2PublicState — no backend changes needed
  • New trick: When "New Trick" state, history trail shows nothing (or last trick winner for context)

Component Architecture

  • PlayArea.vue — Gains a new playHistory prop (readonly Big2HistoryEntry[]). Renders PlayHistoryTrail + current play.
  • PlayHistoryTrail.vue (new) — Receives last N history entries, renders mini-cards with aging CSS classes.
  • Props contract: { entries: Big2HistoryEntry[], maxVisible: number, players: PlayerPublicInfo[] }
  • No new composable needed: History is derived from the existing big2State.playHistory slice passed down from GameBoard.
  • Responsive: Desktop = horizontal trail left of current play. Mobile = compact row below current play.
