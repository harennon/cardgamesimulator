Show Previous Played Cards on the Table

Context: Currently, only the lastPlay is shown in the PlayArea center. Full history lives in the GameLog sidebar (desktop) or drawer (mobile). Users want to see the last 2-3 plays directly on the table without opening the log. Three design directions are shown below.

Data source: Big2PublicState.playHistory already contains the full play history (array of Big2HistoryEntry). We slice the last 3 entries for display.
Option A — Horizontal Timeline (Cards Drift Left)
Previous plays slide left and shrink as new plays arrive. The current play stays centered and large. Older plays fade and reduce in size, giving a natural sense of time flow across the felt. Passes are shown as dashed outlines so the visual rhythm is maintained.

Option B — Scattered Layers (Cards Left on Table)
Cards appear to be physically left on the felt at slightly different positions with subtle rotations. The current play is centered, older plays drift left with reduced opacity and slight rotation angles. This feels most like a real card table where previous plays are pushed aside. Most organic feeling, but uses more horizontal space.

Option C — Left Sidebar Mini-History
A compact vertical strip on the left side of the table area shows the last 3 plays in a list format. This is the most information-dense option and least disruptive to the existing layout. The current play remains centered and prominent. The sidebar uses tiny cards for maximum density. Best for mobile adaptation — collapses cleanly into existing drawer.

Component Architecture (All Options)
GameBoard.vue PlayArea.vue (modified) TurnTimer (existing) PlayHistory (NEW) -- renders last N plays PlayHistoryEntry (NEW) -- single previous play (cards + label) GameCard (existing) -- reused with size="small" or "tiny" CurrentPlay (extracted) -- the current lastPlay (was inline in PlayArea) Props flow: GameBoard passes big2State.playHistory to PlayArea PlayArea slices last 3 entries, passes to PlayHistory PlayHistory renders each entry with shrinking scale/opacity New CSS variables: --card-history-width: 34px --card-history-height: 48px --history-entry-opacity-oldest: 0.45 --history-entry-opacity-recent: 0.65 --history-entry-scale-oldest: 0.72 --history-entry-scale-recent: 0.82
State Management
No new composable needed. Data already available: - big2State.playHistory: readonly Big2HistoryEntry[] - big2State.lastPlay: Big2Play | null Computed in PlayArea: const recentPlays = computed(() => { const history = props.playHistory; if (history.length <= 1) return []; // Show last 2-3 entries BEFORE the current lastPlay return history.slice(-4, -1); }); Mobile behavior: - On mobile (max-width: 767px), hide PlayHistory - Recent plays remain visible in the drawer/log only - Keeps table area uncluttered on small screens
