Tonk — Game Board

UI for the second game type. Tonk is a draw-and-discard game: each player holds 5 cards and races to minimize their hand value. The board reuses the existing casino-felt system (opponent row, center table, bottom hand, side log, action bar) but swaps Big2's "last play" trick area for a two-pile center (stock + discard) and adds a live hand-value total and the signature Call TONK action.

Rules note for the architect / CEO: the attached rules variant is a value-minimization game (Aces=1, faces=10, jokers=0, sum your 5 cards). It has no spreads, no melds, and no hitting — unlike the rummy-style Tonk the issue scaffold assumed. The turn is strictly discard 1 → draw 1; "Call TONK" replaces "win by emptying your hand." This mockup is designed to the attached rules. Multi-trick scoring runs to 150 points. Flagging the scope difference for sign-off.
