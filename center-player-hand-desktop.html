Center the player's hand on desktop

Issue #147 — the desktop hand is left-aligned in a full-width strip, so a small hand feels shoved into the corner. Below are three centering strategies. Use the controls to switch option, viewport width, and hand size. The key thing to check: with a full 13-card hand in a narrow window, are the leftmost cards still reachable (not clipped)?

Option A — Auto-center (recommended)

Your hand (5)

Option A — auto-center (margin-inline: auto): hand hugs left when it overflows (fully scrollable, nothing clipped), and centers when it fits. Label stays pinned left. Safest — recommended default.

Option B — justify-content: center: simplest, but with a full hand in a narrow window the leftmost cards clip off the left edge and can't be scrolled to (a known flexbox + overflow bug). Try Option B + narrow + full to see the failure.

Option C — centered tray: label centered above the cards, hand centered via margin-inline: auto. Same overflow safety as A, more visually balanced, but changes the label position from beside the cards to above them. Bigger visual change.

All three leave the existing @media (max-width: 767px) mobile rules untouched — switch Viewport to Mobile to confirm the mobile layout is unchanged (stacked label + left-aligned scroll).
