Component Architecture Notes 

GameLobbyView.vue (updated)
  Props: { gameId: string, players, maxPlayers, isHost, actionPending }
  New computed: shortCode — first 8 chars of gameId, uppercased, split into 2 groups of 4
  New method: copyGameCode() — copies shortCode, shows toast

  Template additions:
    .invite-section (replaces current .lobby__invite)
      span.invite-label  — "Room Code"
      .invite-code       — tap target, contains code text + copy icon
      span.invite-toast  — "Copied to clipboard" (shown 2s after tap)
      button.invite-link — "Copy Full Invite Link" (secondary, existing behavior)

  Layout: Flexbox column, centered. Code display is full-width within panel.
  Responsive: Already inside the lobby panel which has max-width and padding.
             On mobile (<767px), panel padding reduces (28px 20px vs 40px 48px).

State:
  codeCopied: ref<boolean> — drives toast visibility + icon swap
  setTimeout resets after 2000ms

No new composables needed — purely local component state.
