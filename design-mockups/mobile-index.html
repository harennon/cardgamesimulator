Mobile Big2 Layout Mockups

Three distinct approaches to making the game board work on phones (375px wide). View each at phone width using your browser's responsive mode or on an actual device.

A: Stacked Compact

Everything fits on screen without scrolling. Opponents as thin strip, cards at 44x62px with -14px overlap, game log hidden behind drawer toggle. Minimal: just the essentials.

B: Scrollable Hand with Floating Actions

Prioritizes card readability. Larger cards (48x68px) in a horizontally scrollable hand. Action buttons float above the hand for immediate access. Avatar-based opponent bar.

C: Landscape-Optimized (Two-Row Portrait)

Designed for landscape play with portrait fallback. In portrait, cards split into two rows (7+6) to avoid overlap. In landscape, actions move to a side panel. Orientation hint included.

Viewing tip: Open each link in Chrome DevTools responsive mode set to 375x667 (iPhone SE) to see the portrait layout. For Direction C, also try 667x375 to see the landscape adaptation.
